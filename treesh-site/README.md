# Chainz 2.0 for Treesh

This folder mirrors the live site layout, so each file goes to the same path in the **Treesh** repo on the **main** branch.

| File in this folder | Put it in the Treesh repo (branch `main`) at | Live URL |
|---|---|---|
| `games/chainz.html` | `games/chainz.html` (next to `frea.html`, `nects.html`, …) | https://treesh.app/games/chainz |
| `index.html` | `index.html` (repo root; replaces the current one) | https://treesh.app |

## Why the live URL is a 404 right now
treesh.app is served by **Netlify** from the `main` branch.
- Netlify serves `games/frea.html` at `/games/frea`. That's why FREA!, Nects and VocoTap work.
- There is currently **no `games/chainz.html` on `main`**, so `/games/chainz` returns 404.
- A new branch created by "Save to GitHub" is **not** what Netlify publishes. At most it gets a branch preview. The file has to land on `main`.

## Steps (about 2 minutes, all in the GitHub website)
1. Save to GitHub into the Treesh repo as a new branch, for example `chainz-v2`.
2. On GitHub, switch to that branch and open `treesh-site/games/chainz.html`. Click **Download raw file**.
3. Do the same for `treesh-site/index.html`.
4. Switch to the **main** branch and open the `games` folder.
5. Click **Add file → Upload files** and drop in `chainz.html`. Choose **Commit directly to main**.
6. Go back to the repo root on **main**. Use **Add file → Upload files** again to upload `index.html`, which replaces the old one. Commit to main.
   - This step is needed for live Starlite, profile and accent sync while Chainz is open inside Treesh.
7. Netlify redeploys automatically, usually within about a minute. Then open https://treesh.app/games/chainz.

> Do **not** merge the whole branch into `main`. It contains the development workspace (`frontend/`, `backend/`, `tools/`, …), which your site doesn't need.

The file is about 1.7 MB because the JS, CSS and the 20,000-word bank are all inlined. Netlify gzips it, so players download roughly 450 KB.

## How the sync works
Chainz and Treesh are both on `treesh.app`, so they share localStorage and IndexedDB.

Chainz reads and writes the exact keys Treesh already uses:
- `treesh_profile`: nickname, avatar and zodiac. You can edit your nickname in Chainz and it writes back to your Treesh profile.
- `treesh_accent`: your accent colour, which becomes the game colour and updates live. You can override it in Chainz Settings → Theme colour.
- `treesh_stars`: your Starlites wallet.
  - Awards and purchases are logged in the same `{t, a, r}` format. Purchases are negative amounts.
  - Each Chainz run adds 1 to `games`.

The patched `index.html`:
- listens for `storage` events and `chainz:sync` messages and refreshes its in-memory Starlites and profile, so Treesh never overwrites Starlites that Chainz just awarded.
- includes a postMessage bridge (`TREESH_GAME_ORIGINS`) in case a game is ever hosted on another domain.
- shows spends as negative amounts in "Recent rewards".
- includes Chainz data in the "Games & rewards" export/reset group.

Chainz's own data:
- `localStorage.chainz_save_v2` holds settings, inventory, cosmetics, trophies, bests and stats.
- IndexedDB `chainz_db` holds `assoc` (the word lookup cache) and `runs` (your last 60 runs with their chains).
- Old Chainz high scores (`difficultyScores`) are migrated automatically.

## Starlite rewards
**During a run**
- Each link: +1
- Every 5-link combo: +5
- Answer under 2.5s: +2
- Golden word: +10

**After a run**
- Run with 5+ links: +10
- New personal best: +15
- First run of the day: +10
- Daily Chain: +30, plus +5 per streak day (up to +50 more)

**Trophies:** +15 / 30 / 60 / 120 (bronze / silver / gold / platinum)

**First launch:** a one-time +100 welcome gift

In-run earnings are then adjusted:
- Multiplied by difficulty (×1 / 1.2 / 1.5 / 2) and by mode (Zen ×0.5, Sudden Death ×1.5, …).
- Doubled by a Starlite Booster.
- Halved once you've earned more than 600 Starlites in a day. This soft cap doesn't apply to trophies.

## Editing and rebuilding
- Source code is in `frontend/src`:
  - `game/`: engine, Treesh bridge, storage, audio, data
  - `screens/`: UI screens
  - `components/cz/`: UI kit
- To rebuild both files, run `bash treesh-site/build.sh`.
- The word bank is `frontend/public/data/chainz-bank.json`. It's generated by `tools/genbank.py` from the original 326 prompts plus the free Datamuse API.
- Add `?debug=1` to the URL to get test helpers (`window.__chainz.answers()`). Players never see these.
