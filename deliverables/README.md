# Chainz 2.0 — Treesh Games

Chainz has been rebuilt as a React app and shipped as **one self-contained file**. The JS, CSS and the 20k-word bank are all inlined, and no backend is needed.

## Deploy (drop-in replacement)
| File | Where it goes in the `treesh` repo (branch `main`) | URL |
|---|---|---|
| `chainz.html` | Replaces the old `games/chainz.html`. Keep the exact same file name. | https://treesh.app/games/chainz |
| `index.html` | Replaces your Treesh `index.html`. This is your file plus a small live-sync patch. | https://treesh.app |

That's it. Commit and push, and GitHub Pages serves `games/chainz.html` at `/games/chainz`.
- The file is about 1.7 MB, but GitHub Pages gzips it, so players download roughly 450 KB.
- If your old file has no `.html` extension, just name the new one the same way you named the old one.
- Treesh's `GAMES` list already points at `https://treesh.app/games/chainz`. That's the same origin as Treesh, so localStorage and IndexedDB are shared and sync is instant.

Rebuild after editing the source: `bash deliverables/build.sh`. It regenerates `chainz.html` and the patched `index.html`.

Where things live:
- Source code: `/app/frontend/src`
  - `game/`: the engine (words, Treesh bridge, storage, audio, data)
  - `screens/`: UI screens
  - `components/cz/`: UI kit
- Word bank: `/app/frontend/public/data/chainz-bank.json`, generated by `/app/tools/genbank.py` from your original 326 prompts plus Datamuse.

## Treesh integration (seamless sync)
Chainz reads and writes the exact keys Treesh already uses:
- `treesh_profile`: your nickname, avatar and zodiac. You can edit your nickname in Chainz and it writes back to your Treesh profile.
- `treesh_accent`: your accent colour, which becomes the game colour. It updates live. You can override it in Settings → Theme colour.
- `treesh_stars`: your Starlites wallet.
  - Every award or purchase is added to `log` in the same `{t, a, r}` format Treesh uses. Purchases are stored as negative amounts.
  - The Chainz run count increments `games`.

**Same origin** (Treesh at `treesh.app` and Chainz at `treesh.app/games/chainz`, which is your setup) is the ideal setup, because localStorage is shared.
- The patched index.html listens for `storage` events and `chainz:sync` messages.
- It refreshes its in-memory Starlites and profile, so Treesh never overwrites Starlites that Chainz just awarded.

**Cross-origin** (only if you ever host a game on another domain, like `treesh.life`) is handled by a postMessage bridge.
- Chainz sends `chainz:award` and `chainz:spend` messages, and Treesh applies them to its own wallet.
- Allowed origins are listed in `TREESH_GAME_ORIGINS` inside the patched index.html.


Chainz's own data:
- `localStorage.chainz_save_v2` holds settings, inventory, cosmetics, trophies, bests and stats.
- IndexedDB `chainz_db` holds `assoc` (the Datamuse lookup cache) and `runs` (your last 60 runs with their chains).
- Old Chainz high scores (`difficultyScores`) are migrated automatically.

## Starlite rewards
| During a run | |
|---|---|
| Each link | +1 |
| Every 5-link combo | +5 |
| Answer under 2.5s | +2 |
| Golden word (random ~8% of prompts) | +10 |

| After a run | |
|---|---|
| Run with 5+ links | +10 |
| New personal best | +15 |
| First run of the day | +10 |
| Daily Chain | +30, plus +5 per streak day (up to +50 more) |
| Trophies | +15 / 30 / 60 / 120 (bronze / silver / gold / platinum) |
| First-launch welcome gift | +100 (one time) |

- In-run earnings are multiplied by difficulty (×1 / 1.2 / 1.5 / 2) and by mode (Zen ×0.5, Sudden Death ×1.5, …).
- A Starlite Booster doubles in-run earnings.
- Once you've earned more than 600 Starlites in a day, further run earnings are halved. This soft cap doesn't apply to trophies.

## QA helper
Open the game with `?debug=1` to expose `window.__chainz.answers()` and `window.__chainz.state()` for automated testing. Leave it off for players.
